# Kilo Code CLI

Installs the [Kilo Code CLI](https://kilo.ai/cli) from GitHub Releases and makes `kilo` available on `PATH`.

## Example Usage

```json
"features": {
    "ghcr.io/sachitv/devcontainer-features/kilo-code:1": {
        "version": "latest"
    }
}
```

## Options

| Options Id | Description | Type | Default Value |
|-----|-----|-----|-----|
| version | Version of the Kilo Code CLI to install, or `latest`. | string | latest |
